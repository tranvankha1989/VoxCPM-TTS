========================================================
   HƯỚNG DẪN CÀI ĐẶT OMNIVOICE TTS TRÊN MACOS
   (Hỗ trợ cả Apple Silicon M1-M4 & Intel Mac / Máy ảo)
========================================================

1. YÊU CẦU HỆ THỐNG:
   - macOS 12 (Monterey) trở lên.
   - Hỗ trợ cả 2 dòng chip:
     + Apple Silicon (M1/M2/M3/M4): Tăng tốc qua GPU Apple Metal (MPS).
     + Intel Mac / Máy ảo x86_64: Tự động chạy chế độ tương thích CPU.

2. CƠ CHẾ KIỂM TRA THÔNG MINH TRƯỚC KHI CÀI:
   - Tất cả các bước đều TỰ ĐỘNG KIỂM TRA xem máy đã có sẵn phần mềm/thư viện đó chưa.
   - Nếu máy bạn ĐÃ CÓ SẴN (ví dụ đã cài Python 3.11 hoặc FFmpeg từ trước):
     -> Script sẽ hiện dấu tích xanh [✓] và tự động bỏ qua, KHÔNG cài đè lại, giúp tiết kiệm thời gian và băng thông mạng.

3. DANH SÁCH CÁC TẬP LỆNH ĐỘC LẬP THEO TỪNG BƯỚC:
   Bạn có thể nhấp đúp chạy từng file riêng biệt tùy nhu cầu:

   • [1_Kiem_Tra_Va_Cai_Python.command] :
     - Kiểm tra Python >= 3.10 trên máy.
     - Nếu đã có -> Báo thành công và dừng.
     - Nếu chưa có -> Tự động tải và mở bản cài đặt Python 3.11 chính thức (.pkg).

   • [2_Cai_Dat_FFmpeg.command] :
     - Kiểm tra công cụ FFmpeg (dùng xuất audio MP3/WAV và làm phụ đề Whisper).
     - Nếu đã có -> Báo thành công.
     - Nếu chưa có -> Tự động cấu hình FFmpeg cho macOS.

   • [3_Cai_Dat_Thu_Vien_AI.command] :
     - Kiểm tra môi trường ảo backend/venv và kiểm tra xem thư viện AI đã có chưa.
     - Nếu đã cài đầy đủ -> Báo xanh [✓] và hỏi bạn có cần cập nhật lại không.
     - Nếu chưa cài -> Tự động nhận diện chip:
       + Apple Silicon: Cài PyTorch mới nhất (torch >= 2.4) + OmniVoice.
       + Intel Mac / Máy ảo: Cài PyTorch tương thích CPU (torch 2.2.2) + OmniVoice.

   • [4_Tao_Icon_Ung_Dung.command] :
     - Tạo ứng dụng "OmniVoice TTS.app" vào thư mục /Applications.
     - Tạo lối tắt Shortcut ra ngoài Desktop.

   • [Cai_Dat_macOS.command] (KHUYÊN DÙNG):
     - Menu tổng hợp cho phép chọn chạy từng bước lẻ (1, 2, 3, 4), chọn [A] để tự động chạy toàn bộ quy trình, hoặc chọn [U] để gỡ cài đặt.

   • [Go_Cai_Dat_macOS.command] :
     - Gỡ bỏ ứng dụng OmniVoice TTS khỏi máy Mac một cách an toàn.
     - Tự động xóa ứng dụng trong /Applications và shortcut ngoài Desktop.
     - Cung cấp tùy chọn xóa sạch thư mục backend/venv và bộ nhớ đệm cache mô hình AI để giải phóng 5-8GB dung lượng ổ cứng.

4. NẾU GẶP THÔNG BÁO BẢO MẬT (SECURITY & PRIVACY):
   - Nếu macOS hiện thông báo "Không thể mở vì file tải từ internet":
     Vào Cài đặt hệ thống (System Settings) -> Quyền riêng tư & Bảo mật (Privacy & Security) 
     -> Cuộn xuống dưới chọn "Open Anyway" (Vẫn mở) là được.
